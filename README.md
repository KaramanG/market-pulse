# market-pulse

## Разработка функционала для расширения сервиса "Пульс Рынка" Альфа-Банка

Для запуска необходимо догрузить все модули как для фронта и для бека с помощью команды `npm install`

Фронт запускаем через команду `npm run dev`

Бэк запускаем через команду `node server.js`

Дампы БД загружаем в MongoDB в коллекциях `transactions` и `account_history` соответственно
